# 雙共線麥克納姆輪動態平衡機器人

基於 ATmega328P 架構開發的雙輪欠驅動倒立擺平衡機器人。本專案採用硬體定時器（Timer2 CTC）實現微秒級確定性多頻率串級 PID 平衡控制，並具備動態解耦架構，為後續擴充三輪全向平面移動奠定核心基礎。

## 📌 專案概述

本專案研發一款採用共軸麥克納姆輪驅動之自平衡倒立擺機器人。工程核心目標在於：優先攻克難度最高的非線性欠驅動雙輪動態平衡系統，後續透過模組化插槽擴充第三接地輪，在無需旋轉車身的前提下直接實現原生純橫向平移（Lateral Crabbing）。

---

## 🚀 核心實測驗證成果

- **定點直立自平衡**：通過無連續位置漂移之實機驗證，達成 **> 90 秒** 不間斷穩定站立。
- **高精度穩態垂直點**：穩態俯仰角變異量嚴格收斂於 **±0.4°** 範圍內。
- **確定性多頻率中斷排程**：透過 ATmega328P 硬體 Timer2 CTC 定時中斷，將高頻平衡內環時序嚴格鎖定於 **10.13 ms (98.7 Hz)**。
- **靜摩擦死區補償**：導入前饋死區偏移演算法，徹底消除馬達在零交越低速區間的非線性抖動與震盪。

## ⚙️ 控制韌體架構

韌體採用解耦設計之雙頻率串級控制架構：

### 1. 平衡內環 (10.13 ms / 98.7 Hz)
- **感測輸入**：InvenSense MPU-6050 晶片內建數位運動處理器（DMP）輸出之 6 軸姿態融合資料。
- **控制演算法**：比例-微分（PD）控制，負責抑制俯仰傾角與傾斜角速度偏差。
- **實測驗證參數**：
  - $K_p = 1275$
  - $K_d = 70$

### 2. 速度外環 (40.50 ms / 24.7 Hz)
- **感測輸入**：雙通道正交磁編碼器讀取之累計旋轉圈數與回饋速度。
- **控制演算法**：比例-積分（PI）控制，動態微調動態平衡中心點偏移量（$\theta_{\text{offset}}$），維持小車定點站立。
- **實測驗證參數**：
  - $K_p = 2.8$
  - $K_i = 0.005$

## 🛠️ 硬體規格與腳位定義

| 子系統 | 元件 / 規格型號 | 腳位指派 / 通訊介面 |
| :--- | :--- | :--- |
| **主控微控制器** | Microchip ATmega328P (16 MHz) | 硬體 Timer2 CTC 定時中斷 |
| **慣性姿態感測器** | InvenSense MPU-6050 (DMP) | I2C (A4/SDA, A5/SCL) + 外部中斷 INT0 (D2) |
| **馬達驅動模組** | Toshiba TB6612FNG 雙 H 橋驅動器 | PWM: D5, D6 \| 方向控制: D4, D7, D8, D9 |
| **驅動致動器** | 2× 微型金屬直流減速馬達 | 霍爾磁編碼器 (A/B 相中斷) |
| **輪組機構** | 2× 65mm 共線麥克納姆輪 | 高抓地力橡膠滾子組 |
